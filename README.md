## 🔄 工作流

1. **练**：用「提示词/面试提示词.md」开一场面试
2. **存**：新模块 → 套模板新建逐字稿；已有模块 → 在原稿追加问答
3. **登**：新增 / 移动文档后 → 跑「提示词/索引登记提示词.md」登记两级索引（① 回本表登记或更新状态行，② 到所在区块 README 补一行链接 + 定位）
4. **跟**：回本表更新熟练度、日期、待补点
5. **复盘**：每场面试后用「面试整理提示词」沉淀实录，再跑「复盘答案提示词」逐题复盘（当时怎么答 + 代码优先的标准答案）、追加高频错题并回填本表
