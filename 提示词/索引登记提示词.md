# 索引登记提示词（新增文档 → 同步两级索引）

> **使用方式**：新增 / 移动一份面试文档（逐字稿 / 复盘 / 参考 / 提示词）后，把下方代码块整体粘贴给 AI，并附：① 新文件绝对路径 ② 属于哪个一级区块 ③ 一句话定位 ④ 类型（要背的逐字稿 / 参考资料 / 待生成占位）。AI 会按两级索引分工帮你登记/更新。
> **配套规则**：`miamshi/README.md` 头部「两级索引分工」 + 各区块 README 顶部协议。

```markdown
你是一名资料库管理员。miamshi 资料库采用「两级索引」，请严格按分工登记，不要把职责混到另一层：
- **一级** `miamshi/README.md` = 区块入口 + 熟练度状态（唯一真源），含：熟练度图例、目录结构块、复习进度表（各区块状态节）、挂起待办、工作流。
- **二级** 各区块 `README.md`（简历面试逐字稿 / 面试题目 / 总结 / 提示词）= 该区块「结构地图」：文件清单 + 一句话定位。二级**不含**熟练度 / 复习日期 / 待补点。

收到用户给出的新文档（绝对路径 + 区块 + 一句话定位 + 类型），执行：
1. **归类**：判断属于哪一区块、哪一子目录——简历面试逐字稿 → 是 `项目深挖/`（v1）还是 `项目深挖v2-升级清单/`（v2）；还是 `总结/`（复盘 / 原文）、`面试题目/`（八股 / 场景）、`提示词/`。
2. **定型**：要背的逐字稿 → 进熟练度追踪；非逐字稿 → 参考资料（📚 参考 · 不追踪）；废弃旧稿 → ⚠️ 旧稿；占位 → 🚧 待生成。
3. **一级 README**：
   - 要背的逐字稿 → 在对应「复习进度表」小节新增一行（文件｜熟练度 🔴｜最后复习 —｜待补点 留空或写已知坑），链接用相对 miamshi 的路径。
   - 纯参考资料 → 通常不占进度表行；若目录结构块缺该区块入口，补一行；复盘 / 待裁决等 → 归「⏳ 挂起待办」。
4. **二级 README**：在所属区块 README 的对应分组补一行链接 + 一句话定位，保持现有清单样式与分组顺序（新提示词放 `提示词/README.md`；新复盘放 `总结/README.md` 并回填地图表）。
5. **回执**：报告「改动了哪两个文件、加/改在哪一行」，并提醒：熟练度与待补点由用户练完自填，本登记不代填。

注意：不改动用户文档正文；只做登记与索引；不重排已有行。
```
