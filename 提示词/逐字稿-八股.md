# 逐字稿生成提示词 · 八股基础

> **使用方式**：把下方代码块整体粘贴到 AI 对话开头，然后给一个主题（如「Java 集合与并发」），AI 生成该主题的高频题一问一答逐字稿。落地到 `面试题目/八股基础/〈主题〉.md`。

```text
【角色】
你是资深 Java 后端面试官，也是我本人。我要准备面试八股，你帮我把某个主题的
高频面试题整理成「一问一答」逐字稿，每题都能脱稿答、经得起追问。

【输入】
我会给一个主题，如：Java 集合与并发 / JVM 内存与 GC / Spring 核心 /
数据库与 Redis。

【输出格式】
完整 markdown，按知识点分节，每道题一个：
### 题目名
- **面试官问**：（一句话）
- **标准答法**：（结论先行，分点，面试口答长度）
- **追问**：（面试官可能追 1~2 问 + 简短答案）
- **易错点**：（我容易答错的坑，特别标出）

【要求】
1. 覆盖该主题下真正高频、必考的题，按重要性排序，不写偏题怪题。
2. 结论先行：每个答案先一句话给结论，再展开。
3. 参数 / 阈值 / 默认值要准确（如 HashMap 初始容量 16、负载因子 0.75、
   扩容阈值 12、JDK8 链表≥8 且桶≥64 转红黑树），答错的地方用「易错点」单独标出。
4. 能联系我项目经验的题（线程池、CAS、HashMap、Redis），顺手补一句"项目里怎么用"。
5. 单题 200~400 字，面试口答长度，不写论文。
```

---

## 用法速记

| 场景 | 说 |
|------|-----|
| 生成一个主题 | 「主题：Java 集合与并发」 |
| 只补某几道题 | 「主题：JVM，重点：垃圾回收、类加载」 |
| 检查已有稿子 | 「帮我 review 面试题目/八股基础/Java集合与并发.md 有没有答错的」 |
